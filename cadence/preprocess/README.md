# cadence.preprocess — Layer 2: Per-modality preprocessing

Each submodule reads a session's digest (`data/digest/v1/<session_id>.npz`) and
writes a cleaned per-modality artifact under `data/preproc/<modality>/v1/`.

## Submodule contract

Every submodule exposes:

```python
preprocess_<modality>_session(session_id, *,
                              digest_dir, out_dir, force=False) -> dict
```

* **Input:** session_id (string), the session's digest only.
* **Output:** `data/preproc/<modality>/v1/<session_id>.npz` + `<session_id>.json`.
* **Idempotent:** if output exists and `digest_xdf_md5` matches, skip.
* **Per-participant only.** Cross-participant features (interbrain coherence,
  dyadic synchrony) belong in `cadence/coupling/`.

CLI is generated by `cadence.preprocess._cli.make_modality_cli`.

## Submodules

| Module | What it does | Output channels |
|---|---|---|
| `eeg/`  | Bridges MATLAB EEGLAB output (ASR + 1-40 Hz FIR + spherical interp) | `(M, 14)` clean + `(N, 8)` features at 2 Hz |
| `face/` | 52-AU gap-fill (0.5s linear), per-AU z-score, RMS activity; V7 PCA(15) + smoothed-derivatives(15) + activity | `(N, 52)` AU + `(N, 31)` v2 |
| `ecg/`  | 0.5-40 Hz bandpass, R-peak detection, ectopic-beat outlier rejection, 7-ch HRV at 2 Hz | `(M,)` clean + `(N, 7)` features |
| `pose/` | Format dispatch (mediapipe33 / mediapipe33_meta / wholebody_133) -> `(N, 33, 4)`; visibility-aware 40-ch joint-group features + activity | `(N, 33, 4)` + `(N, 41)` features |
| `respiratory/` | Placeholder | |
| `audio/` | Placeholder | |

EEG output sidecars carry the exact MATLAB script parameters (ASR burst
stddev=20, FIR 1-40 Hz, etc.) so the chain is fully reproducible from a
single `digest_xdf_md5` key. Atomic writes + provenance sidecars protect
against partial files (a half-written `.mat.tmp` never has a sidecar; the
bridge skips and re-runs).

The pose submodule's visibility-aware reductions are a **deliberate
behavioral fix** over the legacy unconditional mean: groups with no visible
landmarks return NaN (filtered by NaN-safe stats) instead of biasing the
centroid toward origin. Frames with face occlusion produce different head
features post-migration; this is intended.

## CLI

```bash
python -m cadence.preprocess.eeg  Y_55              # one session
python -m cadence.preprocess.eeg  --all             # every canonical session
python -m cadence.preprocess.pose Y_55 --force      # force re-run
```

## Adding a modality

1. Create `cadence/preprocess/<mod>/__init__.py`, `pipeline.py`, `cli.py`.
2. Implement `preprocess_<mod>_session(session_id, *, digest_dir, out_dir, force=False)`.
3. Add the modality to `cadence.ingest.schema.SUPPORTED_MODALITIES` + `MODALITY_KEYS`.
4. Update `cadence.ingest.digest` to read the corresponding raw stream.
5. Add a smoke test in `tests/preprocess/test_<mod>_smoke.py`.

See `docs/data_pipeline_v1.md` for the canonical schema and migration record.
