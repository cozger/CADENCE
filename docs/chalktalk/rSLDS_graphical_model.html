Reference diagram and equations for the chalk talk (Minutes 10–15)

28D Feature Pipeline — from raw signals to model inputs

Graphical Model

z
Discrete latent state — which coupling regime (NULL, COUP, SHARED, OTHER)
y
Observed emissions — 28D surrogate-calibrated coupling features
Exogenous covariates — 7D inputs that modulate transitions
Recurrent link — y feeds back into next z (the "r" in rSLDS)

Mock Equations (whiteboard-friendly)

1 · Transition (how states switch) P(z_t = k | z_{t-1} = j, y_{t-1}, u_t) ∝ exp( W_jk + R_k · y_{t-1} + S_k · u_t )
W_jk = baseline transition weight from state j → k (shared across sessions)
R_k · y_{t-1} = recurrent term — previous observations influence which state comes next
S_k · u_t = covariate modulation — the 7D inputs (flexibility, asymmetry, …) push transitions
2 · Emission (what you observe in each state) y_t | z_t = k ~ 𝒩( μ_k^(s), Σ_k^(s) )
Session-specific mean μ and covariance Σ — each dyad's physiology is different,
but the state identities and transition rules are shared.
3 · Null state constraint State k = 0 (NULL): μ_0 ≡ 0, diag(Σ_0) ≤ σ²_max
The null state is not learned — its mean is pinned at zero and its variance is capped.
This anchors the model: "no coupling" has a fixed definition, the other 3 states define themselves relative to it.
4 · Fitting (one line summary) Per-session init → Hungarian alignment → hierarchical EM ( shared {W, R, S} ⟷ session-specific {μ_k^(s), Σ_k^(s)} ) → constrained Viterbi (10 s min dwell)
Hungarian alignment solves label switching across sessions before pooling.
10-second minimum dwell is applied post-hoc via constrained Viterbi, not during EM.

Whiteboard drawing tips

Draw order: Start with the z chain (3 squares, left to right). Then drop the y circles below. Then add the u diamonds above. Finally add the red dashed recurrent arrows — save those for last because they're the punchline ("this is what makes it recurrent").

Keep it to one time-slice: On a real whiteboard, you may only need z_{t-1}, z_t with y_{t-1}, y_t, and u_t. Three time steps look cleaner in a reference doc but can clutter a whiteboard.

The one equation to write: If you only write one thing, write the transition equation (Equation 1). It encodes the three key ideas — Markov chain (W), recurrence (R·y), covariate modulation (S·u) — in a single line. Point at each term as you explain it.

Color code if possible: Use blue for the discrete state chain, green for observations, red/orange for the recurrent link. Even with just two marker colors (black + one other), highlight the recurrent arrow — it's what distinguishes this from a vanilla HMM.
